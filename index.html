Sync with GitHub

Saves your entries to a file called journal.json in a GitHub repository, so they show up on any computer. Use a separate private repository for this, because anything in a public repository can be read by anyone. Create a fine-grained access token limited to that one repository with Contents set to read and write, then paste it here. The token is kept only in this browser, so enter it once on each computer.
